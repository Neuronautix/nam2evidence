# Development Documentation

Internal engineering documents: the original planning brief, the phased
implementation plan, and the forward-looking roadmap. These describe how
nam2evidence is being built and where it is going.

They are working documents, not user-facing documentation and not a product
commitment. For usage, see the [Sphinx documentation](../index.rst); for
released changes, see the [changelog](../../CHANGELOG.md).

| Document                                         | Contents                                                                                     |
| ------------------------------------------------ | -------------------------------------------------------------------------------------------- |
| [design-brief.md](design-brief.md)               | Original planning brief: problem statement, product thesis, MVP scope, core artifacts, epics. |
| [implementation-plan.md](implementation-plan.md) | Phased delivery plan with completion state per task, from repository audit onward.            |
| [roadmap.md](roadmap.md)                         | NAM-CORE standardization layer: remaining phases, schema targets, and sequencing.             |
